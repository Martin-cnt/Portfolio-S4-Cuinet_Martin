# Portfolio BUT 2 - Vue 3 (minimal)

Structure simple basée sur Vite + Vue 3 + vue-router.

Installation:

```bash
npm install
npm run dev
```

Le site démarre sur `http://localhost:5173` (par défaut). Le design est en fond noir et texte blanc.

Fichiers importants:
- [index.html](index.html)
- [src/main.js](src/main.js)
- [src/App.vue](src/App.vue)
- [src/router/index.js](src/router/index.js)
- [src/components/Header.vue](src/components/Header.vue)
- [src/pages](src/pages) (pages principales)
